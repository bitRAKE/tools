# Reviews

This folder contains tool review posts written as standalone HTML files:

- `reviews\<tool>.html`

Each review should be a fair, technically grounded critique that covers:

- what the tool does well
- where it is limited
- alternative ways to achieve the same task (including debugger/IDE/native tooling paths)
- how the tool fits into larger development workflows
- a final recommendation (`keep`, `improve`, `deprecate`, or `learning-example`)
